# Aplicativos Barbacue & Co.

Quatro aplicativos Flutter para Android e iOS: **Barbacue Gestão** para a equipe,
**BARBACUE**, **Chelas** e **Barbadog** para clientes. Possuem identidades de
instalação separadas e podem coexistir no mesmo aparelho.
